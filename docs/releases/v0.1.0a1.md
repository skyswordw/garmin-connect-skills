# v0.1.0a1 · 本地 alpha

发布日期：2026-10-08。中国区为主要目标，精确使用 garminconnect 0.3.17。

本版提供安装 → 本地认证 → 按需获取 → 轻量摘要 → 查询或中文事实周报的本地工具，以及一个 Garmin Connect 主 Skill。

- 本地终端输入密码/MFA，token 按账号档案和区域隔离。
- 按需读取睡眠、HRV、静息心率、压力、Body Battery、训练准备度、训练状态与跑步摘要；支持近期 Coach 日程和选中任务详情。
- 失败、真正空记录和可选缺失分别表达；已有成功摘要在更新失败后仍可使用，并标明截至时间和更新错误。
- 中文事实周报配套来源 JSON、日期覆盖和内容 hash，默认防覆盖。Obsidian 可作为显式导出位置。
- 一个 Agent Skill、中文安装与恢复指引、原创图标，以及无需账号的虚构 demo。

验证：macOS arm64 / Python 3.12.8 上 80 项离线回归通过，Ruff 与 Skill 结构检查通过；锁定源码安装、uv tool install 和 wheel 安装在临时环境中通过，CLI 在仓库外执行成功。

GitHub 离线 CI：macOS、Ubuntu Python 3.12/3.14 各 80 项通过，Windows 79 项通过、1 项 POSIX 权限/符号链接测试跳过；四个任务的 Ruff 均通过。

**实测边界：真实 CN 登录、MFA、自然 token 到期恢复、设备字段与 Coach 尚未验证；Windows 终端认证和文件访问权限仍需实机核对，不能据离线测试宣称真实账号兼容。global 为实验性。** 0.3.17 的 JWT-only 会话不能可靠持久化，工具会明确提示并保留原 token。详细状态见 [compatibility.md](../compatibility.md)。

推荐从源码按 [README](../../README.md) 安装并先运行 demo。Release 附本地构建的 wheel、源码包和 Skill ZIP；Skill ZIP 解压后，将完整 garmin-connect 目录放入 Agent 的 Skill 目录，CLI 仍需单独安装。项目尚未上传 PyPI，不额外要求模型 API key、后台服务或笔记库。

反馈时提供版本、平台、账号区域、命令和安全错误码即可，不附密码、MFA、token、身份或真实健康 payload。
